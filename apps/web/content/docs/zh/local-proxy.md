# 本地代理

Agent 的本地代理让工具使用路由令牌，上游服务商凭据保留在 AIPass 中。在**本地代理**中配置，默认监听 `127.0.0.1:8787`。

## 路由与协议

每条路由包含入站协议、本地 bearer 令牌、选择策略，以及引用保险库凭据的目标。入站协议包括 OpenAI Responses、Chat Completions 和 Anthropic Messages。上游使用不同的受支持协议时，可启用转换。

使用 `Authorization: Bearer <route-token>` 传入路由令牌。轮换上游密钥会更新代理凭据，无需将密钥写入工具。路由或凭据变更可能关闭受影响连接，客户端需要重新连接。

可从路由的**快速接入**配置已安装的工具，详见[工具集成](/docs/zh/integrations)。

## Responses WebSocket

Responses WebSocket 客户端连接 `ws://127.0.0.1:8787/v1/responses`，按实际监听地址调整主机和端口。服务商的上游 API 地址仍使用 `https://…` 或 `http://…`。

**优先使用 WebSocket**按服务商配置。原生 Responses 目标可为 HTTP 客户端使用 WebSocket 上游；只支持 HTTP 或需要转换的目标使用 HTTP/SSE。路由可混合这些目标，并保持客户端的响应格式。

连续三次 WebSocket 传输失败后，该服务商会暂时使用 HTTP/SSE。冷却后只允许一个恢复尝试；完整成功的 WebSocket 响应会恢复使用 WebSocket，SSE 成功不会清除 WebSocket 失败记录。

**探测端点**使用已配置的协议、请求头与出站代理。WebSocket 探测发送 `generate: false`、空输入和 `store: false` 的 `response.create`，需要已设置或发现的模型及有效的预热完成事件。缺少模型、认证或额度错误，以及无法确定的失败都不会被当作明确不支持；探测不会修改保存的传输偏好。

## 会话与转换限制

原生 Responses 会话绑定其上游，原样传递响应 ID、增量输入、应用帧和并行通道。

桥接会话在内存中重建对话输入，保留工具定义及匹配的工具结果。服务商绑定的推理内容、文件 ID 和条目引用不会迁移到其他目标。缓存响应不持久化，即使设置 `store: true` 也是如此；未知的响应 ID 需要客户端重新发送完整输入。

服务端会话、后台生成、压缩、生成中途引导，以及桥接不支持的托管工具需要原生 Responses 上游。无法保留的能力会明确拒绝，而非静默丢弃。不支持浏览器子协议认证或独立的 Realtime 音频 API。

## 失败与重试

提交前，或收到明确拒绝后，可选择下一个目标。部分写入、响应中断或其他提交后结果不明的情况，不会自动重放；即使启用静默重试，HTTP、SSE 和 WebSocket 都遵循此规则。

连接与握手建立、套接字写入及重试等待可以设限。已提交的生成不会因首字节、空闲或 hold 等待预算而终止。客户端取消或相关配置变更仍可取消请求。

为命中提示词缓存，可发送稳定的 `X-AIPass-Session-Id` 请求头或 `prompt_cache_key` 字段。会话优先使用健康目标；明确失败后可绑定到健康的回退目标。会话亲和性仅在内存中保存，代理配置刷新后清除。

## 用量与定价

用量按服务商、密钥和模型在本机记录。每个密钥可指定价格规则集和倍率；网关账单参考值与美元估算分开。修改分配会重算该密钥的历史用量；修改共用规则时可选择从现在起应用或应用于全部历史。自动刷新会保留手动分配。

公共模型价格表独立于应用版本更新，自定义规则和倍率优先。估算金额可能与服务商实际账单不同。

`GET /health` 仅检查本地代理存活，不会向上游发请求。

## 局域网控制面板

Agent 提供按需启用的网页控制面板，用于切换凭据和管理代理。它使用独立访问码，可选 HTTPS。若网页会话需要解锁保险库，请在主机生成访问码时明确授予远程解锁权限；Agent 重启后也遵循该授权。控制面板仍使用与桌面应用相同的 Rust Agent。
