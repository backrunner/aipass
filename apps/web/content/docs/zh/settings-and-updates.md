# 设置与更新

## 发布渠道

AIPass 通过 GitHub Releases 发布两个渠道：

- **正式版** —— 以 `vX.Y.Z` 标签发布的稳定版本，由发布工作流产出签名并公证的 macOS 构建。
- **测试版** —— 同一仓库中以 prerelease 形式发布的早期测试版本，可能包含尚未完成的功能。

本站的[下载区](/zh)始终优先选择带有 macOS 安装包的最新**正式版**；只有当尚无可用的正式版安装包时，才会回退到测试版，并在版本号旁标注渠道。

你也可以在应用内切换渠道：**设置 → 更新 → 更新渠道**提供**正式版**和**测试版**两个选项，切换后会立即在新渠道上检查更新。默认渠道跟随当前安装的构建——测试版构建默认在测试渠道，正式版构建默认在正式渠道。如果想直接换渠道而不等更新，从下载区或 [GitHub Releases](https://github.com/backrunner/aipass/releases) 覆盖安装对应渠道的构建即可。

## 自动更新

桌面应用会自动检查更新——启动后不久检查一次，之后每 24 小时最多检查一次——通过读取随每个 GitHub Release 一同发布的更新清单完成。发现新版本时，应用内提示允许你：

- **安装** —— 下载并就地应用更新。
- **忽略** —— 跳过该版本，同一版本不会再次提示。

更新产物带有签名，应用在安装前会验证签名。

## 保险库与同步设置

在桌面应用中你还可以：

- 修改主密码或轮换保险库纪元（CLI 中的 `vault rotate`、`vault change-password`）。
- 管理受信任设备，并撤销不再使用的设备的访问权限。
- 导出加密保险库备份（`vault export`），并在另一台机器上导入。
- 配置本地/iCloud 文件夹或 WebDAV 同步。同步的永远只有加密对象。

完整的 CLI 功能列表见 [README](https://github.com/backrunner/aipass)。
