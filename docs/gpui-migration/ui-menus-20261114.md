# Menu and selector audit — 2026-11-14

Follow-up to [controls and renderer audit](ui-controls-20261114.md), performed while
manual Mac interaction was unavailable. This checkpoint does not accept the entire
migration UI. No production data, credentials, installed app or release was changed.

## Corrections

- Workspace filter/title menus, provider actions, provider/interface/auth form
  selectors, credential protocol and integration key selectors now share the frozen
  reference's 160 ms enter / 120 ms exit timing, easing, opacity, translation and
  subtree scale. Closing options are inert. Add field intentionally keeps its
  reference's immediate menu appearance; disclosure animation is separate.
- Popup position feedback resolves the scale origin before child prepaint, including
  upward flips. Paint, pointer, accessibility and IME geometry read that same origin.
  Auth/modal composition and the pinned vendor renderer were not modified.
- Select menus use measured trigger widths, 32 px ordinary option rows, selected
  checkmarks, focus/hover treatment, 4 px padding, 8 px corners and reference shadow.
  Form popups now anchor to the 28 px value control, not its entire labelled row.
  Long lists have the reference's 16 px scroll-edge fade and an independent inner
  viewport. Home/End and arrow navigation scroll focused items fully into view;
  including padding in the scroll viewport had clipped the last option.
- Provider, protocol, auth and key selectors focus the current choice. Arrow keys
  open a closed selector; Enter chooses, Escape dismisses, and focus returns to the
  trigger. Filtered auth choices retain their original protocol mapping.
- Open form selects use a 2 px accent underline and translucent accent background.
  Credential selects and integration key triggers retain their distinct reference
  focus rings. The integration protocol badge no longer stretches across a row;
  gateway/key group badges and truncation are included.
- The filter menu includes dynamically derived tags. Selection stores tag identity,
  survives tag reordering and clears on navigation, successful add or lock.
- Existing provider Archive/Trash actions now have keyboard navigation, icons,
  danger color, disabled busy state and one-dispatch behavior. Their presentation
  lives in `workspace/provider_menu.rs`; shared select styling lives in
  `menu/select.rs`, below the project source-size limit.
- Read-only provider Advanced uses the shared 220 ms height / 180 ms fade and
  chevron transitions, including reversal and reduced motion.

## Evidence and limits

The automated comparison uses the frozen Svelte implementation in WebKit and
actual offscreen Metal output at 960×640 and 1280×820, English/Simplified Chinese,
light/dark. Reports contain source/binary hashes, PNG pairs and review pages.
Geometry and sampled colors are component gates, not an all-pixel equivalence
claim. Integration comparisons normalize the menu to its trigger because the
surrounding detail pane has known independent layout differences. The runner
scrolls the native container using bounded synthetic wheel events.
