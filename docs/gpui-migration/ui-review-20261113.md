# Component, background and engineering review — 2026-11-13

This is a correction checkpoint, not acceptance of the complete GPUI migration.
The later [presentation and consistency checkpoint](ui-performance-20261113.md)
supersedes the native-window blocker and add-form/scroll-fade issues below.
The [comparison method](component-validation.md) defines the repeatable checks.
All evidence below uses synthetic data and the frozen original UI. No public
release, production vault, commit or push is part of this checkpoint.

## Changes

- Prepare the background scene before its first paint. Reuse cached layers for
  animation; retain the previous scene while a resized scene is prepared.
  Release replaced image-atlas entries instead of accumulating resize textures.
  Retire intermediate jobs even when the window returns to its original size;
  never install an obsolete-size scene. A deterministic native render test
  covers resizing back and moving onward before a job completes.
- Restore the login/unlock background's three drifting gradients and two waves,
  with the original durations, easing, alternating directions and reduced-motion
  behavior. Paint restrained glass from those same layers, keeping text sharp.
- Keep the opaque base at window resolution to avoid magnifying atlas sampling
  at the window edge. Downsample only blurred layers and frosted textures.
- Move auth glass and the card frame outside the scroll viewport. Match the
  reference's final-viewport scroll operation in capture mode; an initial macOS
  frame resize previously left the synthetic bottom-scroll fixture one pixel up.
- Correct provider field backgrounds/dividers, badge height, detail field text
  sizes and the minimum-window add-dialog frame. Use `DialogPopup` so presses in
  the form cannot fall through to backdrop dismissal.
- Record each observed control's geometry and actual declared native style.
  Compare reference text styles on the corresponding text/input leaf, separately
  from its surrounding box. No editor values are included in observations.

## Native-window boundary

`ui-native-20261113-r3` contains the current GPUI comparison binary and shared
icon. Native computer use returned `cgWindowNotFound` / `timeoutReached` through
path selection, running-app selection and a fresh control session. The previously
working managed updater bundle also returned `cgWindowNotFound`. No native input,
resize or displayed-frame-rate result is accepted from these attempts.

The diagnostic process sample also exposed a separate packaging defect: the shell
entry execed a differently named binary, losing macOS bundle identity. The
packager now sets `CFBundleExecutable` to the actual Mach-O and records required
preview arguments in its manifest. The corrected running process resolves bundle
identity/version and the bundle passes deep/strict ad hoc signature verification.
This correction did not restore computer-control access. Launch a comparison
binary with its manifest arguments; an argument-free production launch is not
enabled by a validation bundle.
