## 已确认的原版缺陷

8 个环境组合均复现：图表当天数据从 1200 token / 3 次请求更新为 2400 / 6 后，柱子、无障碍标签和汇总已更新，但保持聚焦的 tooltip 仍显示 1200 / 3。`UsageChart.svelte` 保存了旧 point 对象，刷新数据没有重定位该对象。

这是原版缺陷，不是正确的迁移合同，也没有被悄悄改成通过。证据在基线回放报告 `findings` 和 `proxy-live-tooltip-*.png`。后续原生图表应按日期/小时标识解析最新 point，并覆盖数据移出周期或清空时的提示关闭。
