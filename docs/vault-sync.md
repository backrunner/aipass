# Vault 同步与首次恢复

macOS 使用 **CloudKit 私有数据库**。签名的 Tauri 原生进程负责 Apple 网络传输，Rust Agent 通过已认证的类型化 IPC 派发密文传输任务，并统一负责 vault、验证、合并和冲突。WebDAV、OneDrive 和本地文件夹复用相同的完整加密快照引擎。

## 首次启动

- 默认先检查 iCloud。发现唯一的现有版本后下载完整加密快照，进入解锁页，使用原主密码验证并恢复记录，不创建新 vault。
- 首次检查的等待状态最多保持 15 秒。失败会显示检测失败，后台仍可完成下载；创建前会再次检查已到达的云端内容。
- CloudKit 中无快照时检查旧 iCloud Drive 的 AIPass 目录，迁移已有可恢复快照。旧目录中的占位文件会请求 macOS 下载；内容未到齐时不会当作空目录创建新 vault。
- 首屏支持导入已有 vault 文件夹、加密备份、`.aipsnapshot`、iCloud、WebDAV 和同步文件夹。文件与文件夹支持系统选择器。
- 已有 vault 和同步快照使用原主密码；加密备份使用导出密码，导入后仍用原 vault 主密码解锁。WebDAV 账户密码与 vault 主密码是不同的字段。
- 手动导入先在临时目录完成验证，再安装到正式目录。替换原 vault 时保留原目录备份。导入目录内携带同步设置恢复日志，设置写入失败或进程中断后仍优先读取新 vault 的设置，避免复用旧目标。文件导入默认关闭旧 vault 的同步目标；从同步来源导入会保存所选目标，并加密保存 WebDAV 密码。
- 普通创建必须完成云端复查。无法登录 iCloud、离线或开发包未配置 CloudKit 时，用户可以明确选择“仅在此设备创建”，关闭该新 vault 的自动云同步。

旧版本只上传 `objects` / `devices` / `audit` / `grants`，没有上传恢复所需的密码与密钥封装。**只有这些旧记录的远端无法独立恢复 vault**，检测到时会阻止普通创建，避免把已有内容误认为空目录。在原设备升级、解锁并同步一次，即会先验证和迁移旧记录，再发布可恢复快照；也可从原设备导出加密备份。在所有参与同步的设备上升级后使用新格式，旧客户端不会读取新快照。

## 自动同步

已有 macOS vault 升级后，在正常解锁时自动迁移到 CloudKit；涵盖本地存储、同步文件夹、OneDrive、WebDAV 和旧 iCloud Drive。Agent 先在 `vault/sync-state/cloudkit-migration/` 保存 `source.aipsnapshot` 加密备份与 `source-settings.json` 原设置（WebDAV 密码仍加密），再同步原目标、合并可自动合并的修改。即使另一台设备已经上传 CloudKit，也会检查旧 Drive 的更新。

完整密文上传到 CloudKit 后，Agent 从远端回读并验证哈希、vault 身份和完整内容，确认与当前本地版本一致才持久化切换。此后自动同步只走 CloudKit，界面同步目标随之刷新。迁移中继续编辑、离线、上传失败、回读失败或设置保存失败都会保留迁移状态，后续自动重试；原远端副本和首次加密备份不会删除。旧目标不可达时先等待其恢复；不同 vault、Apple 账户变化或无法自动合并的冲突会停止切换，保留数据供处理。

这是一次升级迁移。新安装默认使用 CloudKit，从 CloudKit 恢复的 vault 无需再迁移；升级后用户明确新建“仅在此设备”或手动选择其他同步模式，会保留该新选择。修复原模式的 WebDAV 密码等设置后，仍继续待完成的迁移。非 macOS 平台保持原同步方式。

本地修改经约 350 毫秒防抖触发同步，连续写入最多等待 2 秒；另有每秒的文件元数据检查，补足 macOS 合并目录事件或漏报。文件夹远端使用文件通知，30 秒轮询补偿漏报和稍后挂载的云目录。WebDAV 每次成功完成后 5 秒再次检查远端，复用 HTTP 连接池；失败逐步退避至 5 分钟，认证失败暂停自动重试 5 分钟，手动同步和重新配置可立即重试。

CloudKit 使用数据库静默推送唤醒同一调度器，60 秒补查防止推送丢失。原生传输使用 zone change token 分页读取修改；只在整批结果成功后提交内存游标，token 失效则重新枚举。CloudKit 的服务端重试延迟会被遵守。推送不保证即时送达，因此这是尽力而为的近实时同步；桌面进程（包含托盘）必须运行，Agent 独立运行时会保留待发送内容直到桌面恢复。

已建立检查点的目标在网络请求前、用户锁定前保存最新的完整密文到待发送目录。锁定后不生成新快照，也不将未经验证的远端内容覆盖已有 vault；可以继续上传待发送密文、下载远端密文，下次正常解锁后验证和合并。WebDAV 密码在磁盘上始终由 vault 密钥加密，进程内仅缓存可擦除的传输密码，锁定不保留 vault 解密密钥。Agent 重启后若仍锁定，需要首次正常解锁才能取回 WebDAV 认证密码。更换目标或账户不会复用旧缓存。目标选择与设置修改、导入和重置共用同步锁，等待中的同步不会在切换完成后继续使用旧目标。后台同步不触发自动解锁、不刷新用户活动时间。

下载和网络传输不占用会话锁。应用已验证快照时才短暂串行化本地读写，完成后刷新内存 vault、代理凭证和桌面列表。有效代理配置未变时不刷新连接；路由代次隔离无关路由的变更，保留现有 HTTP/SSE/WS 会话。凭证撤销或替换会要求受影响路由重新认证；被远端移除的目标从运行配置排除，监听服务与其他路由继续运行。界面通过 Agent 状态获取后台同步状态，本地提交成功不代表另一台设备已经收到。

## 加密、合并与恢复

代理凭据刷新使用 Rust 内部只读接口，不修改密钥使用时间或审计记录，避免同步完成后又产生新的同步修改。已应用的快照即使随后检查点写入失败，也会通知界面并刷新可用的代理配置；重试会合并内容相同的快照分支。

每个 `snapshots/<sha256>.aipsnapshot` 包含密码封装与完整密文记录集合；集合再次使用 vault root key 加密，AEAD 同时认证头部、创建时间和父版本链接。服务端看不到服务商名称、端点、API key 或解密密钥。本机代理运行配置、同步账户设置、缓存和检查点不进入云端快照。

快照不可覆盖，父版本链接记录已合并的历史。不同记录的修改在本地解锁后进行三方合并；同一记录的并发修改或分歧的密钥版本需要用户选择。冲突界面显示版本时间、服务商数量和部分名称。选择一个完整版本会替换对应 vault 数据，其他版本仍可从加密历史导入。

应用快照前先验证全部内容，并写入恢复日志。普通磁盘应用错误会回滚，保持当前解锁会话和代理；若磁盘连回滚也无法写入，则保留日志并暂停 vault 读写，待后台恢复或下次解锁重放，代理继续使用其既有运行快照。中途退出后，下次解锁会重放完整事务，避免密钥和记录只更新一部分。发送失败的快照留在本地加密待发送目录，后续重试；暂时缺少远端文件的目录列表不能让已知版本回退。无法验证的快照进入隔离目录，不能接受为正式数据；不同 vault 或已绑定的 Apple 账户发生变化时拒绝同步。

当前 CloudKit 原生 IPC 将单个加密快照限制为 **11 MiB**，以满足 16 MiB 帧上限；超限返回错误并保留本地数据及待发送内容，不截断。WebDAV 与文件夹不受此 IPC 限制。

历史快照目前保留在同步目标中，存储量会随修改增加。它们也保留历史数据的加密副本，删除当前记录不等于清除历史备份。重置本地 vault 会清理本地同步缓存和待发送内容、关闭同步，不删除云端历史。

## 验证范围

回归测试覆盖：完整恢复、错误密码、密钥轮换和密码更新、篡改拒绝与隔离、中断重放、待发送重试、目录列表回退、独立修改合并、并发冲突选择、代理刷新、旧格式迁移、本地自动发送、WebDAV HTTP 认证/导入/后台轮询及首屏交互。

UI 以 Tauri 最小窗口 `960×640` 验证。真实 Apple 账户跨设备传播、真实 WebDAV 服务兼容性需要使用对应账户另外验证；本地 HTTP 模拟测试不能替代这些结果。

CloudKit 发布前的 Apple 容器、schema、推送和签名配置见 [CloudKit 发布设置](cloudkit-release.md)。未带 iCloud entitlement 的开发包在调用 CKContainer 前返回不可用，避免原生异常；Rust 测试直接覆盖此 Swift FFI 边界，不需要启动正式 App 或访问真实 Apple 账户。
